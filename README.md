# socli Homebrew tap

This tap distributes tagged socli releases for macOS and Linux.

```sh
brew tap massimodeluisa/tap
brew install socli
socli --demo
```

Run `brew update` and `brew upgrade socli` to install a newer release. The formula verifies each download with SHA-256.

Homebrew Core submission is pending its acceptance criteria. This tap provides installation while the project establishes public use.
